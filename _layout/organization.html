Science as Data

A wealth of data on publications, researchers, institutions, and their relationships offers opportunities to study how science works. Alongside this expanding record, interest in the science of science is growing: how knowledge develops, how researchers collaborate, and how research is organized.

Access to these data does not necessarily make them straightforward to analyze. Open projects such as OpenAlex and CORE provide large data dumps, but working with huge collections of nested JSON records requires substantial preparation before analysis can begin. Different sources also offer complementary information that remains disconnected until records are matched across them.

Science as Data is a collection of repositories addressing these preparation and matching needs. The overarching goal is to make science of science data more accessible to researchers who can analyze data but are not specialists in data architecture or engineering. The repositories bring together loading workflows, relational data models, matching methods, and documentation, with the scope and development status of each area described below.

Repositories and available materials

OpenAlex

A snapshot-to-PostgreSQL workflow, relational schema, and SQL examples. Additional repository tools support API exploration, publication-date quality audits, and journal matching.

Available on this site: loading protocol, schema documentation, a publication-date audit summary, and a static sample of 80 works with linked metadata. The sample is not representative.

OpenAlex documentation

arXiv

A metadata snapshot workflow covering papers, ordered author occurrences, categories, revisions, and source provenance in PostgreSQL.

Current scope: the version 303 snapshot contains 3,164,437 unique works. Explore submission-year and month distributions, category breakdowns, and the relational schema.

arXiv documentation

CORE

A loaded 2024 snapshot of 219.97 million works, including 26.37 million stored full texts. Explore the ingestion pipeline, database model, and documented completeness assessment.

Pre-registrations

Implemented collectors for AsPredicted, OSF, ClinicalTrials.gov, AEA RCT, and Zenodo. Explore the fields, provenance, storage options, and coverage limits.

Data matching

A shared home for linking registrations, papers, and journals across sources. The pre-registration matching pipeline and linked-pair analyses have moved into this repository.

Status: pre-registration matching is implemented; journal matching is under development; a general OpenAlex–arXiv matcher is planned, with limited links already checked in the OpenAlex date audit.

Data matching documentation

Project responsibilities

OpenAlex, arXiv, and CORE prepare and assess their source data. The study-preregistrations repository collects registration records. Data matching owns cross-source linkage methods and evaluation, including the migrated pre-registration matcher and linked-pair analyses. The existing journal matcher still resides in OpenAlex. This website presents those projects’ methods, data, and outcomes.

Scope checked against the local project documentation on 15 September 2026. Dataset releases and historical assessments keep their own dates; implemented tools, completed analyses, and planned work are identified on each project page.

Using the materials

For OpenAlex, the loading protocol describes the reference snapshot and environment, the schema documents table relationships, and the SQL examples discuss analytical choices. The static data sample illustrates the representation of records; it does not support population estimates.

The analysis and reproducibility notes discuss coverage, missing metadata, units of analysis, and the information needed to reproduce results.
