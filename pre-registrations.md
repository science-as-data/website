<section aria-labelledby="completed"><h2 id="completed">Completed work</h2><p>Five implemented collectors cover AsPredicted, OSF Registries, ClinicalTrials.gov, AEA RCT Registry, and Zenodo. The repository includes platform-specific command-line tools, parsers, export formats, and offline fixture tests. AsPredicted supports live pages, archived pages, and newer PDF records; AEA RCT supports Dataverse snapshot input.</p><p>Optional PostgreSQL storage is implemented for AsPredicted, OSF, and AEA RCT. File outputs are JSON or JSONL, with CSV available in some workflows. There is no single normalized database shared by all five collectors.</p><p>The May 2026 matching experiments used input collections of 11,746 AEA RCT registrations and 25,436 AsPredicted registrations. These are historical experiment denominators, not current registry totals or a claim of complete collection. Publication-linkage outcomes and dependent analyses now live in <a href="/data-matching/">Data matching</a>.</p></section>

<section aria-labelledby="representation"><h2 id="representation">Identifiers, dates, and provenance</h2><p>Each platform keeps its own identifiers and field meanings. A registration date, a study start date, an archive capture date, and a last-update timestamp describe different events. Missing fields and restricted records must remain distinguishable from observed empty content.</p><p>AsPredicted records retain retrieval source and archive timestamps where relevant. Other collectors can preserve raw API values for fields beyond their standard output. AEA’s parser accepts both older and newer field spellings. Consult each collector’s README for output and raw-payload options.</p></section>
<section aria-labelledby="limits"><h2 id="limits">Coverage and interpretation</h2><p>OSF provider filters define which registries are collected; EGAP is documented through that route. Embargoed or withdrawn records require interpretation using their flags. A Zenodo record is not necessarily a preregistration: query scope and record content must establish eligibility. A clinical trial record may also be registered after a study has begun.</p><p>EUCTR, PROSPERO, INPLASY, Research Registry, and protocols.io remain unimplemented in this repository. Their placeholder directories document collection constraints rather than available datasets. A failed or unavailable fetch is not evidence that a registration does not exist.</p><p><a href="https://github.com/science-as-data/study-preregistrations">Collection documentation and platform scope</a> · <a href="/data-matching/">Matching methods and measured linkage outcomes</a></p></section>
